## Status-change procedure

To change a row:

1. open a `claim-audit` issue naming the ID;
2. preserve the old state in Git history and explain the transition;
3. add a repository proof, independent certificate/verifier, exact
   counterexample, or primary external source as appropriate;
4. update [`STATUS.md`](STATUS.md),
   [`../RESEARCH_HISTORY.md`](../RESEARCH_HISTORY.md), and, for failures,
   [`FAILED_APPROACHES.md`](FAILED_APPROACHES.md);
5. state what the new result does not prove.
