## Known traps

- Source and endpoint bounds are simultaneous; neither can be replaced by a
  residue count or Haar volume.
- Endpoint equivalence is not a left congruence by NG24.
- Signed carry is mandatory by NG28.
- The mod-648 threshold table is an allowed-class upper envelope at equality,
  not an exact boundary set.
- Finite emptiness in a bounded box is not an asymptotic exclusion.
