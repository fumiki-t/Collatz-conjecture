```text

```

which already makes a nonperiodic positive orbit permanently coefficient-safe

and an external-input-independent route, but it is no longer the strategic
bottleneck for the nonperiodic branch if EXT07 is admitted. This observation
does not address nontrivial cycles or exclude the resulting permanent-safe
tail.
