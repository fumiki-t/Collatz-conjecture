## 2. P257 — normalization barrier

Fix any actual positive source S and finite length L>=0. Put

```text
y=T^L(S), Q=# odd inputs before L, c=3^Q/2^L,
H=y/c, B_source=ceil(H)-1.
```

For any positive z define `x_k=T^k(z)` and `q_k` as its odd count before k.
Direct one-step algebra gives

```text
Y_k(z)=2^k x_k/3^q_k,    Y_0(z)=z,
Y_(k+1)-Y_k = 0                        if x_k is even,
Y_(k+1)-Y_k = 2^k/3^(q_k+1) > 0        if x_k is odd.
```

Equivalently `Y_k=z prod_(r<k, x_r odd)(1+1/(3x_r))`. At a hit x_t=y,
the path coefficient is `c_z(t)=y/Y_t(z)`. Consequently `c_z(t)>c`
implies `z<=Y_t(z)<H`, hence `1<=z<=B_source`. The bound is exact even
when H is integral: with H=n/d, `B_source=(n-1)//d`.

Once `Y_k(z)>=H`, every later hit has coefficient at most c. Earlier hits
must still be checked; the implementation tests the normalization threshold
at every visit, and a hit with normalization below H immediately returns
an actual improvement. A repeated state without an earlier hit to y proves
the future cycle omits y. Neither cut uses safety or nonperiodicity.

Budget exhaustion is not one of these mathematical cuts. Candidate or step
budgets produce `UNKNOWN`. Target replay itself is finite; no universal
resource bound is claimed for deciding arbitrary targets.

## 3. P258 — global extension of a finite potential

Let W be any finite subset of the positive integers, with nonnegative
rational values f(x) for x in W. Outside W define `f(x)=y/x`. Require

```text
f(y)=1,
0<=f(x)<=y/x                       (x in W),
f(x)>=a(x) f(T(x))                 (x in W),
f(z)<=c                           (1<=z<=B_source).
```

W need not be forward closed and need not contain y: if y is unlisted its
default value is already one. All sources z<H must be listed, since their
default y/z exceeds c. This observation is also a finite coverage guard in
the independent checker. Sorted, reduced rational rows are a serialization
requirement, not an extra mathematical hypothesis.

**Outside edges.** The finite upper-envelope checks imply `f(v)<=y/v`
for *every* positive v. For any x outside W,

```text
a(x)f(T(x)) <= a(x)y/T(x) <= y/x=f(x),
```

because `T(x)>=a(x)x`. This includes edges entering W from outside, not
just edges leaving W. It is the missing obligation in an incomplete
finite-graph-only argument. The upper envelope cannot be omitted: for y=1,
W={1,2}, f(1)=1, f(2)=3/5, both listed edge inequalities hold, but the
unlisted edge 4->2 violates `f(4)>=f(2)/2`.

Multiplying the resulting global inequalities along any finite positive
path z->y gives `f(z)>=c_z f(y)=c_z`. If z<=B_source, the finite source
check gives c_z<=c. Otherwise z>=H and `f(z)<=y/z<=c`. Empty paths satisfy
the same argument. Strict improvement is therefore impossible at all
lengths and all odd counts, without a finite-depth extrapolation.

**Constructing a certificate after completed barrier search.** Take the
finite union of all visited states, plus y. Set f(y)=1. Set any internal
cycle omitting y, and its internal predecessors, to zero. At open exits
use y/x, and propagate edge products backwards along the remaining finite
functional graph. Each assigned value is zero or is `y/Y_t(x)` for a
stopped path, hence at most y/x. The edge from y is valid by the same
upper envelope, even though y was treated as a stopping vertex.

For each candidate source, an endpoint-omitting cycle gives f(z)=0. A
normalization cut gives a stopped upper value at most c. Merging the visited
paths may only extend that stopped path, decrease its upper value by
monotonicity, or change it to zero. If the cut is at y, its assigned value
is exactly the default one. Thus all candidate caps hold. This proves
existence of a finite potential whenever search finishes without improvement;
the verifier nevertheless checks every inequality independently.

These potentials are endpoint-specific super-solutions, not a globally
decreasing rank and not positive-cycle elimination certificates.

## 4. P259 — exact completeness scope

Let N be the set of positive ordinary sources with nonperiodic future.
P221 and the product identity give finite `Ycal(n)=lim Y_k(n)>n` on N.
If N is nonempty, choose n0 in N. The nonempty sublevel
`{n in N:Ycal(n)<=Ycal(n0)}` is finite since n<Ycal(n0). A minimizer on
it is a global minimizer S_* on N. This is the all-positive P242 reproof,
not well-ordering the real numbers and not choosing a least ordinary source.

Fix any finite L for S_*. Every infinite positive orbit has infinitely many
odd inputs, so `H=Y_L(S_*)<Ycal(S_*)` strictly. There are finitely many
candidate sources z<H. If z is nonperiodic, then
`Ycal(z)>=Ycal(S_*)>H`, so monotone convergence forces a finite cut.
If z is eventually periodic, it cannot hit the nonperiodic endpoint y;
the search either cuts earlier or detects its endpoint-omitting cycle.
Equivalently its normalization diverges because a positive cycle has
coefficient below one: in `x=(3^q x+B)/2^L`, B>0 and q>0.

P243 rules out a strict improving hit: a positive source coalescing at y
is nonperiodic and the cocycle gives
`c_z/c=Ycal(S_*)/Ycal(z)<=1`. Hence every candidate terminates and P258's
construction supplies a finite certificate for this fixed prefix.

Quantifiers are `if N is nonempty, there exists S_* such that for every
finite L there exists a finite terminating run and certificate`. This is
not a uniform bound in L, not an arbitrary-target decision procedure, and
not an effective recognition of the last join in P247.

A genuinely infinite, uncut candidate branch (not a finite timeout) would
be injective, omit y, and have `Ycal(z)<=H`. For a nonperiodic target S,
this gives `Ycal(z)<Ycal(S)`. It contradicts a global minimum, but need
not contradict a merely endpoint-maximal target in another future class.
The finite certificate language therefore still contains every prefix of
a hypothetical genuine counterexample representative; it does not solve H112.

## 5. P260 — an auxiliary uniform 13S bound

This theorem is not used to accept a P258 certificate; its H is always
computed from the finite target. The inherited internal inputs are:

- P228's odd-shell capacities O_N, with the general image recurrence A_m.
- P220 and E54's exact finite sum plus geometric tail from N=501, giving
  `sum_(N>=49) c_N/2^N <2079/1000`, where c_N is actual odd shell
  occupancy. Correction (2026-09-10): use raw O_N only through 500 and
  P220 on c_N beyond 500; no all-scale bound on raw O_N is inferred. See
  [`Phase 38 Sections 4–5`](../finite-capacity-renewal-transfer/REPORT.md).
- E46: every positive n<583561 reaches 1, by E28 and 141,780 first-descent
  rows plus strong induction. See
  [`Phase 33`](../../../PHASE33_RUN_RESULTS.md).

The five inherited evidence files are hash-pinned in
[`phase43_capacity.json`](../../../artifacts/phase43_capacity.json) and
in the verifier. They are reused, **not regenerated or fully replayed** in
Phase 43. The dependency property tests additionally recompute the old
capacity generator through N=500 and its tail comparison, not all of E54's
independent evidence. In particular the E54 tail is not inferred from the
new N<=48 reconstruction. E46 depends on E28; no external X02 cutoff is used.

Every state of a positive nonperiodic orbit is at least 583561 and hence
at least 2^19. Its distinct odd states form an equal-time collision-free
set; otherwise two equal-time images would give a periodic future. Apply
P228 to each shell `[2^N,2^(N+1))`. Exact independent reconstruction gives

```text
sum_odd 1/x < 2079/1000 + sum_(N=19..48) O_N/2^N
            = 32986055029845591/4398046511104000 <751/100.
```

Using positive terms of `log t=2 sum_(r>=0) u^(2r+1)/(2r+1)`,
where `u=(t-1)/(t+1)`,

```text
log 2 > 2/3+2/81+2/1215 =842/1215,
log(13/8)>2*(5/21)=10/21,
3 log13 =9 log2+3 log(13/8) >7244/945 >751/100.
```

Finally `log(Ycal(S)/S)=sum_odd log(1+1/(3x)) <(1/3)sum_odd1/x <log13`.
Thus **Ycal(S)<13S**, also for even S. All strictly improving ancestors
of all its finite prefixes have `1<=z<13S`. This bounds sources, not join
times or word lengths; optimizing 13 is not the current bottleneck.

## 6. P261 and NG46 — prefix propagation, not monotonicity

If an earlier target prefix had a strict coefficient improvement, appending
the actual remaining suffix would preserve that strict coefficient ratio
at the final endpoint. P258 at the final endpoint rules this out. Thus one
endpoint certificate covers every target prefix from zero through L.
In particular every nonempty such prefix is coefficient-safe, because
otherwise the empty path from its endpoint has larger coefficient.

Odd defect is `a_j=floor(j log_2 3)-E_j`, where E_j is the full-step time
of the j-th odd state, and the initial odd source has E_0=a_0=0.
The accepted [`small certificate`](../../../artifacts/phase43_certificate_7.json)
for (7,4) yields

```text
7 -> 11 -> 17 -> 26 -> 13,
(j,x_j,E_j,a_j)=(2,17,2,1) -> (3,13,4,0).
```

Every prefix is all-length/all-Q coefficient-maximal, yet defect decreases.
This is the least positive source, then least length, for this *finite*
hypothesis. Even sources already fail safety at step 1. For sources 1,3,5,
the first unsafe step is respectively 2,4,2; the earlier odd defects do not
decrease. No longer prefix from them can be all-prefix maximal. For source
7 the first odd-defect decrease is at step 4. These finite observations,
together with prefix propagation, prove minimality without an all-length
search. The declared grid contains 21 certified queries with a decrease,
including (703,80).

The supplied longer control is preserved exactly:

```text
T^80(703)=1256, Q=51,
H=1518410829435974243430957056/2153693963075557766310747,
B_source=705,
(43,50165,62,6) -> (44,4703,67,2), e=5.
```

Its potential has **1,188** vertices, including 5024 but not its successor
2512; the open exit is covered by P258. The independently forward-closed
reference has **1,189** vertices. Do not conflate them. The certificate
proves maximality for all 81 prefixes including the empty prefix, not just
up to some competitor length cap.

NG46 does not refute a separately quantified statement about an infinite
global minimizer: neither 7 nor 703 is asserted to be such a source. P254
remains valid with its monotonicity hypothesis. A future general variation
budget must survive both finite examples rather than silently invoke P254.

## 7. E59 — implementation and independent audit

[`src/phase43_search.py`](../../../src/phase43_search.py) follows candidate
orbits and constructs stopped-graph potentials.
[`verifier/verify_phase43.py`](../../../verifier/verify_phase43.py) imports
no search implementation, has no barrier-search function and no potential
solver. It reconstructs literal targets/witnesses by positional affine sums
and checks rational inequalities directly. The diagnostic work/cut counters
are explicitly not inputs to its mathematical acceptance.

The second reference method checks a complete, reachable, forward-closed
positive set containing 1..705, explicitly checks all its observed cycles
contract (only {1,2} occurs), and builds first-hit coefficients by reverse
graph traversal. Later cycle visits cannot improve the first hit. Together
with the exact source bound this is complete, not a time-limited oracle.
All 2,668 distinct queries agree: **185** certified no strict improvement,
**2,483** actual improvements. Full potentials and witnesses are retained,
not just counts or a successful-run flag.

The 703 generator reports 25,848 transitions, maximum branch length 92,
254 normalization cuts and 451 endpoint-omitting cycles. These are
reproducible search diagnostics, not mathematical verifier fields. N<=48
capacities are reconstructed via binomial/Fraction arithmetic in generation
and Pascal rows/integer enclosures in verification. Tests cover essential
upper-envelope and coverage tampering, even/empty/unsafe/cycle inputs,
strict-versus-equal gain, bad numeric types, and both resource-UNKNOWN paths.

Regressions preserve all six mandatory families (61 rows), NG22/24/25/26/28,
NG43/44/45, source 167, source 7, q=22 negative carry, negative cycles, and
the formal-versus-ordinary distinction (22 named controls). An intermediate
development verifier incorrectly restricted the square-index lag in the
formal control to j=1,4; the independent comparison rejected it. It was
repaired to the full square-index/b_j=1 condition from the existing proof,
and the final regression passed. No accepted old artifact was changed.

Reproduction, final test scope, commits and SHA-256 are recorded in
[`PHASE43_RUN_RESULTS.md`](../../../PHASE43_RUN_RESULTS.md).

## What this result does not prove

It does not prove arbitrary-target search termination, an effective last
coalescence index, a uniform certificate-size bound, nondecreasing defect on
infinite minimizers, or a contradicting maximum-defect/variation inequality.
It does not turn a timeout into a smaller-height source, or an individual
finite maximal target into an infinite counterexample. It does not eliminate
positive nontrivial cycles or resolve H112, H72, H89, H133 or Collatz.
